# 🏥 myClinic Frontend

A responsive web application developed for a clinic management system, allowing patients and healthcare professionals to manage appointments, medical exams, analyses and prescriptions through an intuitive user interface.

## About

myClinic is a clinic management platform developed as an academic project for the Bachelor's Degree in Web Information Systems and Technologies.

The frontend provides an intuitive and responsive interface where patients can schedule and manage appointments, while healthcare professionals can manage consultations, exams and analyses efficiently.

## Features

- User authentication
- Patient dashboard
- Doctor dashboard
- Appointment scheduling and cancellation
- Exam and analysis management
- Medical prescription viewing
- Appointment history
- Doctor and specialty filtering
- Responsive design for desktop and mobile devices

## Technologies

- Vue.js
- Vue Router
- JavaScript
- Bootstrap
- HTML5
- CSS3
